# Refinar plan

Utiliza esta skill antes de diseñar o implementar funcionalidades nuevas,
refactorizaciones amplias, cambios de arquitectura o modificaciones de base de datos.

## Procedimiento

1. Lee AGENTS.md y la documentación relacionada.
2. Examina el código existente sin modificar archivos.
3. Resume brevemente lo que entendiste.
4. Identifica requisitos ambiguos, contradicciones, riesgos y decisiones pendientes.
5. Formula una sola pregunta por turno.
6. Siempre que sea posible, ofrece entre dos y cuatro opciones concretas.
7. Indica cuál opción recomiendas y explica brevemente por qué.
8. No preguntes aspectos que puedan resolverse examinando el repositorio.
9. Continúa preguntando hasta resolver las decisiones que cambien materialmente la solución.
10. Presenta el plan final con:
   - objetivo;
   - alcance;
   - decisiones tomadas;
   - archivos afectados;
   - cambios de datos y API;
   - seguridad y permisos;
   - pruebas;
   - criterios de aceptación;
   - riesgos;
   - tareas ordenadas.
11. Solicita aprobación antes de implementar.
12. No modifiques archivos durante esta etapa.
